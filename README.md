MOONTRIP is a bilingual (ES/EN) tactical web simulator that trains young explorers as Quarantine and Life Support (ECLSS) Officers inside an Artemis lunar base airlock at the Shackleton Crater. It addresses the Build a Junior Astronaut Mission Trainer challenge by translating real NASA-STD-3001 and NASA BVAD parameters into hands-on mechanics where players balance four critical subsystems: Oxygen, Radiation Shielding, Nuclear Power (Kilopower), and Hydroponic Biomass (APH). Connected live to the NASA DONKI and NASA NeoWs APIs, real-time solar flares and near-Earth asteroids dynamically alter station radiation and power while players inspect arrivals using dual-spectrum X-Ray/UV scanners and perform first-person EVA repairs. This project is vital because it bridges complex aerospace telemetry and accessible STEM education: built on a zero-external-asset procedural architecture (code-driven SVG and Web Audio API), it runs instantly in any classroom browser worldwide without heavy downloads.
